# Песенная стужка

Лічбавая гульня ў духу Hitster з беларускай музыкай. Адзін тэлефон ці ноўтбук перадаецца па крузе. Песня гучыць з YouTube, але назва схаваная пад «пласцінкай».

## Як запусціць

YouTube не грае, калі адкрыць `index.html` проста як файл, таму патрэбны лакальны сервер. З тэчкі праекта:

```bash
python -m http.server 8765
```

Потым адкрыйце http://localhost:8765.

Каб гуляць з тэлефона, выкладзіце тэчку на любы статычны хостынг (GitHub Pages, Netlify, Cloudflare Pages). Спатрэбяцца толькі файлы `index.html` і `songs.js`.

## Як дадаць ці выправіць песню

Усе песні ляжаць у `songs.js`, адзін радок на песню:

```js
{"artist": "Песняры", "title": "Вологда", "year": 1976, "yt": "XXXXXXXXXXX", "lang": "ru", "spotify": null, "confidence": "high"},
```

- `year` — год **першага** выдання гэтага запісу, а не перавыдання ці зборніка.
- `yt` — id відэа: 11 сімвалаў пасля `watch?v=` у спасылцы YouTube. Відэа павінна дазваляць убудаванне. Калі гульня піша «Відэа не грае», знайдзіце іншую загрузку.
- `lang` — мова песні (`be`, `ru`, `en`). Па ёй працуе фільтр «Мова» на стартавым экране.
- `tags` — жанры: `Поп`, `Рок`, `Эстрада`, `Фолк`, `Хіп-хоп`, `Інды`, `Метал`. Па іх працуе фільтр «Жанр» на стартавым экране.
- `confidence` — `low` азначае, што год варта яшчэ раз праверыць.

## Правілы

Яны ёсць у самой гульні, у раздзеле «Правілы» на стартавым экране.
